# Indigo Interiors

Website for **Indigo Interiors** — the boutique interior decorating studio
of Mia Szukalski, serving Greater Sydney since 2017.

Live at **https://indigointeriors.com.au**

Static HTML/CSS/JS — no framework, no build step. Served by GitHub Pages
from this repository.

## Adding a project to the gallery

Projects are folders under `assets/projects/`: photos plus one
`project.json` describing them. See
[`assets/projects/HOW-TO-ADD-A-PROJECT.md`](assets/projects/HOW-TO-ADD-A-PROJECT.md)
for the step-by-step guide.
